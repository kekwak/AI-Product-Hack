Основные моменты, на которые стоит обращать внимание в аналитической
документации.

Спецификация сериализации — в обязательном порядке указывается модель входного и выходного потока данных (формат, схема, тип сериализации/десериализации).

Привязка к источникам — обязательно наличие прямой ссылки на Дата-каталог.

Описание витрин данных — для каждого поля витрины явно указывается признак обязательности (NOT NULL / NULLABLE).

Типовые фильтры — в документации фиксируются стандартные условия фильтрации, применяемые на этапе построения витрин и выгрузки.

Сохранение структуры шаблона — все разделы шаблона должны быть сохранены. При отсутствии обогащения, фильтрации или иных этапов обработки это явно прописывается формулировкой «не применимо.

Инфраструктурные параметры — обязательно указывается кластер Kafka для потоковых источников/приёмников.

Хранение данных — для всех файловых хранилищ прописывается полный путь в HDFS с указанием формата.

Нормативно-справочная информация — в описание каждой витрины включается перечень используемых справочников.
