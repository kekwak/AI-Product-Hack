# Каталог инъекций

`dataset/error_catalog.json` — фактический каталог мутаций, используемый генератором. В нем 97 записей:

- по 3 проявления каждой доменной ошибки `D01–D08` — 24 варианта;
- 16 проявлений единого класса несоответствия шаблону `T01`;
- по 3 проявления каждой универсальной ошибки `U01–U19` — 57 вариантов.

Каждая запись задает только стабильный `mutation_id`, `error_type_id`, `source_type`, `difficulty`, `title` и `problem`. Все 97 мутаций хотя бы один раз представлены в итоговом корпусе. Составная мутация может менять несколько связанных мест документа, но остается одной логической ошибкой с одним `error_type_id`.

Сложность означает стоимость корректного исправления:

- `low` — локальное уточнение одного параметра;
- `medium` — согласование одного правила или контракта в нескольких местах;
- `high` — смысловое либо архитектурное решение с изменением нескольких разделов и тестов.

Сначала генератор выбирает уникальные классы ошибок, затем наименее использованный применимый вариант каждого класса. Поэтому в одном документе нет дублей `error_type_id`, а варианты распределяются по корпусу равномернее. `T01` остается одним типом ошибки, и в документе допускается не более одного `T01`.

Источник истины по фактическому распределению — `dataset/manifest.json`, по конкретному документу — его одноименный JSON-файл в `dataset/corrupted/`.
